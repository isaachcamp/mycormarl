# ADR-0005: Separate construction-carbon efficiency from uptake scale

**Status:** Accepted

## Context

We need a diagnostic showing how plant phosphate uptake changes with absorber
radius and absorber length density, while distinguishing the benefit of more
absorbing surface from the carbon required to construct it. The sparse closure
also makes this comparison useful for visualising the role of the
concentration-like resistance `k`.

The existing model supplies two relevant experimental conditions: a
fixed-bulk-concentration reservoir, which isolates transport and uptake
performance, and a finite-inventory soil cell, which measures realised uptake
while available phosphate is depleted.

## Decision

Create two paired figures over logarithmic grids of absorber radius and length
density:

1. **Efficiency figure:** time-integrated P uptake per construction carbon and
   maximum P uptake rate per construction carbon.
2. **Scale figure:** the corresponding absolute integrated P uptake and
   maximum uptake rate.

Each figure has fixed-reservoir and finite-inventory rows, with integrated and
maximum uptake as columns. The surfaces use plant-side economics. For target
length `L = lambda * V_i`,

    Delta B = L / (k_root * SRL)
    C_construction = gamma_c * Delta B

No above-ground growth, maintenance, or reproduction cost is included.

Run the experiments through an isolated closure-level, fixed-geometry harness.
The diagnostic does not construct or step `BaseMycorMarl` and does not run
organism growth, policy code, or multi-agent dynamics.

Do not add a separate uptake-per-length surface. For the plant-economics sweep,

    uptake / C_construction
      = (uptake / L) * (k_root * SRL / gamma_c)

so construction-carbon and length normalization differ only by a constant
factor and show identical structure across radius and length density.

Use configured `T_ref` as the common horizon for both figures. Add a separate
timescale figure showing `t_1% = min{t : C_s(t) <= 0.01 C_s(0)}` for
finite-inventory simulations across the same geometry grid, with the reference
lambda=2000 cm cm^-3, fungal absorber radius, and configured `T_ref` marked.

Mark three reference cases on every efficiency and scale surface:

- plant geometry with plant-native economics;
- fungus geometry evaluated with plant economics; and
- fungus geometry with fungus-native economics.

The third marker is an explicitly off-surface comparison: it uses fungal
biomass-to-hypha conversion, fungal `gamma_c`, and fungal uptake traits to
measure fungal P gained per fungal carbon.

Initial phosphate and other environmental parameters use model defaults. The
fixed-reservoir concentration is held constant; finite-inventory simulations
begin from the same default phosphate state and allow depletion.

## Consequences

- Absolute scale cannot be mistaken for construction efficiency.
- Fixed-reservoir and finite-inventory results remain interpretable as
  different experiments rather than mixed normalisations.
- The efficiency surfaces are directly comparable to plant growth accounting
  and sparse resistance `k`.
- The fungal-native marker is not generated by the plant-economics surface and
  must be labelled accordingly.
- The measured `t_1%` diagnostic can expose cases where `T_ref` is a poor proxy
  for depletion development.
- Closure behaviour can be qualified without confounding it with growth or
  environment transitions.
- A time-evolving depletion-gradient radius requires a separate diagnostic and
  is not implied by these fixed-`T_ref` surfaces; see Issue #27.

## Parameters recorded for the initial implementation

- absorber radius: `1e-4` to `3e-2` cm, logarithmic;
- length density: `1e-1` to `1e4 cm cm^-3`, logarithmic;
- default plant point: `r_a=1e-2 cm`, `lambda=1`;
- default fungus point: `r_a=5e-4 cm`, `lambda=2000`;
- common efficiency/scale horizon: configured `T_ref` (one day by default).
